# 插件地址与同名登记

公开详情地址为 `/plugin/{owner_github_login}/{name}`。用户名来自登记者在市场保存的 GitHub OAuth 用户名，不从仓库 URL 或 metadata.author 推导；组织仓库同样使用提交者的市场用户名。

`owner_github_login` 是插件登记时的快照。用户之后重新授权并更新 GitHub 用户名，不会自动改变已登记插件地址。权限绑定稳定的 `owner_user_id`；OAuth 账号匹配使用 GitHub ID，不能仅凭复用用户名转移账号或插件权限。

数据库迁移 `20260910_005_plugin_namespace` 移除全局 name 唯一约束，增加 owner_user_id/name 和大小写不敏感用户名/name 唯一索引。原插件 ID、评论、点赞和 Artifact 外键保持不变。新登记优先保留未占用的名称 ID，已有同名 ID 时分配不透明 ID；并发分配在事务中按名称加锁。同一用户、同一名称不能静默换绑另一个仓库。重命名和账号合并产生冲突时返回 409。

新接口 `/v1/plugins/by-author/{username}/{name}` 只返回已上架插件；现有 ID 接口继续用于交互和工作台。旧 `/plugin/{id}` 返回 301 跳转到规范地址，未知或下架详情返回实际 404，过期预渲染文件也不能绕过状态检查。

插件 feed 使用稳定插件 ID 作为对象键及 `market_plugin_id`，`name` 保留实际插件名，避免同名条目相互覆盖。已核对 AstrBot v4.26.6 源码对 `name`、`market_plugin_id` 和 repo 的读取逻辑；市场允许同名条目不代表 AstrBot 能同时加载两个同名 Python 插件模块。

主页支持 `view=waterfall` 分批追加，保留分页模式；`page` 和重复 `tag` 参数可恢复浏览状态。标签按任一匹配，第一项“全部”清空选择。临近下一批时最多并发预载两个图标、最多预载下一批前六项，节流或省流网络跳过预载。

提交页首次进入读取 OAuth 仓库列表，后台每 60 秒刷新。隐藏页面暂停，切回页面或网络恢复时按冷却时间刷新；后台刷新保留选择和填写内容，不显示加载状态，实际提交和发布仍重新验证权限。
